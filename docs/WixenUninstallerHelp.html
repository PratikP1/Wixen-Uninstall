Wixen Uninstaller Help

Wixen Uninstaller removes supported consumer security suites and common leftover companion products from 64-bit Windows 10 and Windows 11 systems.

Keyboard shortcuts

  • Tab and Shift+Tab move between buttons.
  • Enter or Space activates the focused button.
  • Esc goes to the next product page, goes back, or quits.
  • F1 opens this help file while Wixen Uninstaller is focused.

Supported products

  • McAfee Total Protection, LiveSafe, and WebAdvisor leftovers
  • Norton 360, Norton Security, Secure VPN, and Utilities leftovers
  • Avast Antivirus, Avast Premium Security, Secure Browser, and Cleanup leftovers
  • AVG AntiVirus, AVG Internet Security, Secure Browser, and TuneUp leftovers

Running the tool

  1. Launch Wixen Uninstaller. It requests Administrator rights, so accept the Windows UAC prompt.
  2. Select the product you want to remove.
  3. Review the generated removal plan.
  4. Start the cleanup and review the completion report.
  5. Restart Windows. Removing kernel drivers and services only fully takes effect after a reboot.

Reading the completion report

The report separates two different outcomes, because they need different responses from you:

  • Errors are actions that failed, usually because the product was actively defending itself.
  • Skipped for safety means Wixen deliberately left something alone. This happens when a driver file could not be removed safely: its service was still registered, and deleting the file anyway could stop Windows from starting. Rerunning from Safe Mode normally clears both.

Safe Mode note

If Avast or AVG reports access denied errors during normal cleanup, reboot into Windows Safe Mode and run Wixen Uninstaller again. Their self-protection drivers block removal while Windows is running normally.

Removing Wixen Uninstaller

To uninstall Wixen Uninstaller itself, open Settings > Apps > Installed apps, or Add or Remove Programs, and remove it like any other Windows app.
