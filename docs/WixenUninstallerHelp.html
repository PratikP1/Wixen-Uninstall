Wixen Uninstaller Help

Wixen Uninstaller removes supported consumer security suites and common leftover companion products from 64-bit Windows 10 and Windows 11 systems.

Keyboard shortcuts

Wixen uses standard Windows dialogs, so every screen works entirely from the keyboard and reads correctly in NVDA, JAWS, and Narrator.

  • Tab and Shift+Tab move between controls.
  • Up and Down move between the product buttons on the first screen.
  • Enter or Space activates the focused control.
  • Alt plus the underlined letter activates a button directly — Alt+R for Remove it, for example.
  • Esc cancels the current screen or quits.
  • F1 opens this help file from any Wixen screen.

The screens

Choose a product
Each supported product is its own button, labelled with the product name and the companion leftovers its cleanup also sweeps up. Choose one to continue, or Cancel to quit without changing anything.
Confirm the removal
Shows how many actions will run. Expand Show what will be removed to read the exact folders, driver files, services, scheduled tasks, and registry keys first. Focus starts on Cancel, so pressing Enter by reflex never begins a removal.
Progress
A progress bar tracks the work, and the text names each stage as it starts. A removal cannot be interrupted part-way, because stopping half-finished can leave the product in a broken state.
Result
Reports what succeeded. If anything failed or was skipped, expand Show details for the full list.

Supported products

  • McAfee Total Protection, LiveSafe, and WebAdvisor leftovers
  • Norton 360, Norton Security, Secure VPN, and Utilities leftovers
  • Avast Antivirus, Avast Premium Security, Secure Browser, and Cleanup leftovers
  • AVG AntiVirus, AVG Internet Security, Secure Browser, and TuneUp leftovers

Running the tool

  1. Launch Wixen Uninstaller. It requests Administrator rights, so accept the Windows UAC prompt.
  2. Choose the product you want to remove.
  3. Review the removal plan, expanding Show what will be removed if you want the full list.
  4. Start the cleanup and review the completion report.
  5. Restart Windows. Removing kernel drivers and services only fully takes effect after a reboot.

Reading the completion report

The report separates two different outcomes, because they need different responses from you:

  • Errors are actions that failed, usually because the product was actively defending itself.
  • Skipped for safety means Wixen deliberately left something alone. This happens when a driver file could not be removed safely: its service was still registered, and deleting the file anyway could stop Windows from starting. Restart Windows and run Wixen again to finish clearing it — a normal restart usually releases the service's hold.

Self-protecting products (Avast and AVG)

Avast and AVG load a kernel driver that blocks removal while Windows is running normally. You do not need Safe Mode — which is important, because Windows 10 often loads no audio driver in Safe Mode, so a screen reader cannot start there. Wixen handles this automatically:

  • It runs the product's own silent uninstaller first, which can switch off self-protection from the inside.
  • For anything the product locks, Wixen takes ownership where it can, and queues whatever is still locked for deletion during your next restart.
  • If files were queued, Wixen registers itself to run once more automatically after you restart, to finish the cleanup. Just restart Windows normally when it is convenient — your screen reader and audio work as usual, and you do not need to do anything else.

Removing Wixen Uninstaller

To uninstall Wixen Uninstaller itself, open Settings > Apps > Installed apps, or Add or Remove Programs, and remove it like any other Windows app.
