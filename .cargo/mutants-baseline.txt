# Mutants that survive on purpose, checked by CI.
#
# Every entry here must be an *equivalent* mutant — one where the mutated
# program is identical to the original, so no test could ever tell them apart.
# Anything else surviving is a gap in the tests and must fail the build.
#
# Lines are the contents of `mutants.out/missed.txt` with the line and column
# numbers stripped, so the list survives edits elsewhere in the file.
#
# `|` and `^` agree whenever their operands share no bits. Both entries below
# are ORs of disjoint bit sets, and each has a test asserting that disjointness
# (`the_always_on_flags_share_no_bits`, `make_range_operands_never_overlap`),
# so if a future change makes the operands overlap, that test fails and the OR
# starts carrying real weight again.
src/ui/task_dialog.rs: replace | with ^ in Dialog::flags
src/ui/task_dialog.rs: replace | with ^ in make_range

# The stats.ini section boundaries: `[Common]`'s start and end are always
# `[...]` header lines, which carry no `=` and so are never key lines. Widening
# an inclusive/exclusive boundary by one therefore includes only a non-key line
# and cannot change which key is rewritten. `a_section_header_is_never_a_key_line`
# records that invariant; if a header could ever be a key, that test fails.
src/stats_ini.rs: replace > with >= in rewrite_within_common
src/stats_ini.rs: replace < with <= in rewrite_within_common
src/stats_ini.rs: replace + with * in section_contains_key

# The `--resume` entry point, replaced wholesale by an early success. Mutation
# runs on Linux, where `take_pending_resume` is a no-op returning `None`, so the
# real function also does nothing but return success with no output — the mutant
# is indistinguishable here. Its only divergence is on Windows, where it would
# skip a real resume; that is the unverifiable Windows I/O layer this crate
# documents it cannot exercise in CI. The `delete !` mutant on the same function
# *is* caught, by `resume_mode_with_nothing_pending_exits_quietly` in cli.rs, so
# the elevation guard stays pinned; only this equivalent-on-Linux return is excused.
src/main.rs: replace resume_suspended_removal -> io::Result<ExitCode> with Ok(Default::default())
